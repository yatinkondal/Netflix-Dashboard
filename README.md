# Netflix Content Analysis Dashboard | Power BI

## Project Overview

This project is an interactive Power BI dashboard developed to analyze the Netflix content catalog. It provides insights into movies, TV shows, genres, content duration, directors, and country-wise distribution.

The project demonstrates the complete data analytics workflow, including data cleaning, transformation, data modelling, DAX calculations, and interactive dashboard development.

## Project Objectives

* Analyze the distribution of Movies and TV Shows.
* Identify the most common content categories and genres.
* Understand movie duration and TV show seasons.
* Analyze content by country and director.
* Build an interactive dashboard for exploring the Netflix catalog.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* CSV Dataset

## Dataset

The dataset contains 8,807 Netflix titles and 12 columns.

| Content Type | Count |
| ------------ | ----: |
| Movies       | 6,131 |
| TV Shows     | 2,676 |
| Total Titles | 8,807 |

## Data Cleaning & Transformation

* Handled missing director and country values.
* Converted date and year columns into appropriate data types.
* Split duration into numerical values and units.
* Created separate movie duration and TV show season columns.
* Extracted primary categories from genre information.
* Created helper tables for Countries, Directors, and Categories.

## Dashboard Features

### KPI Cards

* Total Movies

* Average Movie Duration

### Visualizations

* Movies vs TV Shows distribution
* Titles by primary category

### Interactive Filters

* Primary Category
* Country
* Director

## Key Insights

* Movies account for approximately 69.6% of the catalog.
* TV Shows account for approximately 30.4%.
* Dramas are the largest primary category, with 1,600 titles.
* The average movie duration is approximately 99.6 minutes.
* The average TV show duration is 1.76 seasons.
* Approximately 67% of TV shows have only one season.
